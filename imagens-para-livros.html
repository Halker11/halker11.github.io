Imagens para livros

Lê o DOCX de um livro didático, encontra as orientações de imagem, sugere fotos de banco pela API e gera o documento final.

TipoFerramenta de automação editorial
StackTypeScript · Python · APIs
Quero ver funcionando

O problema

No original de um livro didático, cada imagem é pedida por escrito, no meio do texto. Alguém precisa localizar cada pedido, procurar a foto num banco de imagens e devolver o documento com as escolhas.

Como funciona

01LeituraAbre o DOCX e identifica as orientações de imagem espalhadas pelo texto.
02SugestãoPara cada orientação, consulta o banco de imagens pela API e traz opções.
03Documento finalGera o DOCX de volta, com as imagens indicadas.

Limites

A ferramenta sugere; a escolha de cada imagem continua com quem edita o livro. O código é privado, por ser de uso interno.
